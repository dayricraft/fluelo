# FluentWork English App — Design System (DESIGN.md)

## Brand & Product Overview
A modern, friendly, and structured English learning web application built around 5 focused daily menus:
1. **Uji Level Awal (Placement Test — CEFR A1–C2)**
2. **Kuasai 500 Kosakata Aktif (Operational Verbs & Daily Business Phrases)**
3. **Pahami 3 Tenses Utama (Simple Present, Simple Past, Simple Future for Office Communication)**
4. **Metode Comprehensible Input & Shadowing (15-Minute Daily Audio & Direct Imitation)**
5. **Praktik Berbicara Komunikasi Dua Arah (Peer-Level Speaking Ecosystem)**

Visual language combines a clean SaaS Bento-grid dashboard with warm, approachable pastel surfaces, pill-shaped interactive controls, and playful flat vector illustrations.

## Component Specifications

### 1. Gooey Vertical Dark Sidebar
- **Width**: `50px`
- **Structure**: Top active circular bubble (`50x50px`, `#1B1A22`) with inner purple circle (`28x28px`, `#3F3161`) connected via a `22px` wide concave neck to a vertical rounded pill (`border-radius: 28px`, padding `18px 0`, gap `24px`) housing 5 icon buttons (`18x18px` stroke icons) for the 5 core English learning menus.
- **Detached Utility Buttons**: Below the dark dock, place a `48x48px` soft grey (`#F7F8FC`) notification bell button with a `7px` coral dot (`#EE6B5E`), and a bottom `48x48px` logout button.

### 2. Category Filter Pills (Sub-Header)
- **Height**: `38px`, padding `9px 15px`, `border-radius: 999px`, `font-size: 12.5px`, `font-weight: 600`, icon + text gap `7px`.
- **Active State**: `1.5px solid #7A82EB`, background `#F4F5FF`, text `#555CE0`.

### 3. Learning Progress Sparkline Cards
- **Layout**: 2-column grid (`gap: 14px`) inside a `#FAFAFE` wrapper (`padding: 18px`, `border-radius: 24px`).
- **Anatomy**:
  - Top row: Icon + Menu title (`12.5px` bold) on left; progress ratio pill (`312/500` or `2.5/3`) on right.
  - Middle row: Large percentage (`27px` bold) on left; smooth cubic-bezier SVG wave line (`92x32px`, `2px` stroke) on right.
  - Bottom row: Bold micro-heading (`11.5px`) + 2-line muted explanation (`10.5px`).

### 4. Core Module Illustration Cards (Menus 1, 2, 3)
- **Layout**: 3-column grid (`gap: 12px`).
- **Card Style**: `#FFFFFF` background, `1px solid #F1F2F8`, `border-radius: 22px`, `padding: 10px 10px 14px`.
- **Top Thumbnail**: `112px` height, `border-radius: 16px`, pastel fill (`#FCEBF2`, `#FDF5E6`, `#EBF0FF`) with centered flat vector illustration.
- **Footer**: Module title (`12.5px` bold), short subtitle (`10.5px`), and star rating (`⭐ 4.9`, `11.5px` bold).

### 5. AI Learning Plan & CEFR Level Switcher (Middle Column)
- **Title Highlight**: Second line `"Created by AI"` wrapped in a `#7772F6` pill (`color: #FFFFFF`, `padding: 2px 10px`, `border-radius: 999px`).
- **Level Switcher**: Horizontal row of compact pills (`CEFR A2`, `CEFR B1`, `CEFR B2`). Active pill uses `#1B1A22` background and `#FFFFFF` text.
- **Stage Cards**: Rounded `22px` containers (`#F3F7FD` and `#FDF1F6`), `padding: 14px 16px`, containing a top badge row and a 3-column icon grid (`46x46px` circular tinted icon wrapper + `11.5px` title + `10px` duration).

### 6. Featured "Shadowing Craft" Card (Right Column — Menu 4 & 5)
- **Container**: Full height of the Bento grid, `border-radius: 28px`, `padding: 22px`, cream-to-white vertical gradient.
- **Hero Illustration**: Centered mascot illustration (`210x215px`) with floating circular glass/pastel badges (`44x44px`) on the left and a rank pill (`#F4F2CE`) on the right.
- **Rating Wreath**: `52x52px` circular badge with `5.0` bold score next to the title.
- **Bottom KPI Pair**: 2 equal columns (`gap: 12px`), `#F4F5F9` background, `border-radius: 20px`, `padding: 14px 16px`, displaying daily audio target (`15m`) and active vocabulary target (`500`).
