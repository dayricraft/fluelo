# Bundled Anti-Slop Skills

The original six `SKILL.md` files provided by the owner are copied to `.agents/skills/`, along with the two optional helper scripts from `antislop-human` and original core reference `antislop.md`. Their license is included in `docs/THIRD_PARTY_LICENSE_ANTISLOP.txt`.

Recommended application during UI work: `antislop`, `antislop-ui`, `antislop-human`, `antislop-layoutmobile`; for prose use `antislop-copywriting`; for code comments use `antislop-code`.

These skills are partly web-oriented. Kotlin/Jetpack Compose guidelines in the project design docs take precedence over any web-specific CSS/HTML instructions. Brand-approved chromatic glow and restrained functional bento design remain intentional.
